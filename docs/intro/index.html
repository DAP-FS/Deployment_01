Tutorial Intro

Let's discover Basic Terminologies in Theory of Computation.

info

Welcome to the first tutorial of Theory of Computation.

In this module, we will slowly build the foundations needed to understand how machines “compute” and what problems they can or cannot solve.

1. What is Theory of Computation?​

Theory of Computation (TOC) is a branch of computer science that:

  • Studies abstract models of computation (like DFA, NFA, PDA, Turing Machines).
  • Classifies problems based on whether they are solvable / decidable.
tip

This concept help us understand the limits of computers:

01. What can be computed?
02. What cannot be computed?
03. How efficiently can it be computed?

It provides the mathematical foundation behind compilers, programming languages, formal verification, and complexity theory.

2.1 Alphabet (Σ)​

Alphabet (Σ)
An alphabet is a finite, non-empty set of symbols.

  • Notation: Σ (capital Sigma)
Alphabet – Quick Examples
  • Σ = {0, 1} → binary alphabet
  • Σ = {a, b, c} → three-symbol alphabet
  • Σ = {a, b, …, z} → lowercase English letters

💡 Intuition: An alphabet is like the “character set” you are allowed to use to form strings.

2. Basic Terminologies​

2.1 Alphabet (Σ)​

Alphabet (Σ)
An alphabet is a finite, non-empty set of symbols.

  • Notation: Σ (capital Sigma)
Alphabet – Quick Examples
  • Σ = {0, 1} → binary alphabet
  • Σ = {a, b, c} → three-symbol alphabet
  • Σ = {a, b, …, z} → lowercase English letters

💡 Intuition: An alphabet is like the “character set” you are allowed to use to form strings.

2.2 String (or Word)​

A string (or word) is a finite sequence of symbols taken from an alphabet Σ.

  • If Σ = {0, 1}, then some valid strings are:

    • 0
    • 1
    • 01
    • 10110

  • A string can have:

    • Length 0 → empty string, denoted by ε (epsilon)
    • Length n → written as |w| = n (where w is the string)
String – Examples

Consider Σ = {a, b}:

  • Valid strings:
    • a, b, ab, ba, aab, bba
  • Invalid string:
    • c is not a string over Σ because c ∉ Σ.

🔎 Key Idea: A string is just an ordered list of characters from the alphabet.

2.3 Empty String vs Empty Set​

These two look similar but mean very different things.

Empty String vs Empty Set
  • ε → the empty string
    • A string with length 0
    • |ε| = 0
  • ∅ → the empty set
    • A set that has no elements at all
Example Over Σ = 1
  • {ε} → a language with exactly one string, and that string is the empty string.
  • ∅ → a language with no strings.

⚠️ Common Mistake:
Don’t confuse {ε} (one element: the empty string) with ∅ (no elements).

2.4 Language​

A language is simply a set of strings over an alphabet Σ.

Formally:

A language L over alphabet Σ is any subset of Σ*
(where Σ* is the set of all possible strings over Σ, including ε).

Language – Examples (Σ = 1)
  • L1 = {0, 1, 01, 10} → a finite language
  • L2 = { w | w contains at least one 1 } → an infinite language
  • L3 = ∅ → the empty language
  • L4 = {ε} → language with only the empty string

🤖 Machines & Languages:
DFA, NFA, PDA, Turing Machines – all of them can be seen as language recognizers:
they accept or reject strings from Σ*.

3. Operations on Strings​

Given strings x and y over some alphabet Σ, we can define several operations.

3.1 Concatenation​

Concatenation means joining two strings end to end.

  • If x = "ab" and y = "ba", then
    xy = "abba"
Properties of Concatenation
  • Identity with empty string:
    • xε = εx = x
  • Associative:
    • (xy)z = x(yz)
  • Not necessarily commutative:
    • Generally, xy ≠ yx
      (e.g., "ab" · "ba" = "abba" but "ba" · "ab" = "baab")

3.2 Length of a String​

The length of a string w is denoted by |w|.

Length – Examples
  • If w = "abba", then |w| = 4
  • If w = ε, then |ε| = 0

📏 The function | · | just counts the number of symbols in the string.

4. Operations on Languages​

Let L1 and L2 be languages over the same alphabet Σ.
We can combine them using set-like and string-like operations.

4.1 Union​

L1 ∪ L2 = set of strings that are in L1 or L2 or both.

Union – Example
  • L1 = {a, b}
  • L2 = {b, c}

Then:

  • L1 ∪ L2 = {a, b, c}

✅ Use union when you want a language that accepts strings allowed by either of two languages.

4.2 Intersection​

L1 ∩ L2 = set of strings that are in both L1 and L2.

Intersection – Example
  • L1 = {a, b}
  • L2 = {b, c}

Then:

  • L1 ∩ L2 = {b}

🎯 Intersection gives the set of strings that satisfy both conditions (belong to both languages).

4.3 Difference​

L1 − L2 = set of strings that are in L1 but not in L2.

Difference – Example
  • L1 = {a, b}
  • L2 = {b}

Then:

  • L1 − L2 = {a}

➖ Think of L1 − L2 as:
“Start with L1, then remove anything that is also in L2.”

4.4 Concatenation of Languages​

The concatenation of languages L1 and L2 is:

L1 · L2 = { xy | x ∈ L1 and y ∈ L2 }

That is, take any string from L1, follow it by any string from L2.

Concatenation of Languages – Example
  • L1 = {a, b}
  • L2 = {c, d}

Then:

  • L1 · L2 = {ac, ad, bc, bd}

🔗 This is like nested loops:
for each x in L1, pair it with each y in L2.

4.5 Kleene Star (L*)​

Given a language L, the Kleene star L* is:

The set of all strings that can be formed by concatenating
zero or more strings from L.

  • Important: L* always includes ε.
Kleene Star – Examples

  1. Let L = {a}

    • L* = { ε, a, aa, aaa, aaaa, … }
    • All strings of only a’s, including the empty string.

  2. Let L = {ab}

    • L* = { ε, ab, abab, ababab, … }
    • Repeating "ab" any number of times (including 0 times).

🌟 Kleene star is used heavily in regular expressions and regular languages.

5. Why Are These Basics Important?​

All upcoming concepts in Theory of Computation rely on these basic terms.

How These Concepts Are Used Later
  • Finite Automata (DFA/NFA)
    • Need: alphabet, states, transition function, language accepted.
  • Regular Expressions
    • Built using: union (+ / |), concatenation, and Kleene star (*).
  • Decidability & Complexity
    • Talk about:
      • What inputs (strings) look like.
      • What set of strings (language) a machine accepts or rejects.

Pracices alphabet, string, language, and their operations
makes later topics (DFA, NFA, CFL, Turing Machines) much easier.

2.1 Alphabet (Σ)

An alphabet is a finite, non-empty set of symbols.

Notation: Σ (Sigma)

Examples
  • Σ = {0, 1} – binary alphabet
  • Σ = {a, b, c} – alphabet with three symbols
  • Σ = {a, b, …, z} – lowercase English letters

💡 Intuition: Think of an alphabet as the “character set” available to form strings.

Quick Quiz – Alphabet (Σ)​

Q1. Which of the following is a valid alphabet?

A. { }
B. {0, 1}
C. {a, b, c, …} with infinitely many symbols
D. {a} but we allow a to appear infinitely many times

Details

Show Answer ✅ Correct: B

  • An alphabet must be finite and non-empty.
  • A is empty → ❌
  • C is infinite → ❌
  • D is weirdly phrased, but as a set {a} is finite and non-empty; however, the intended clean example here is B.

Q2. True or False:
“An alphabet is always a set of letters from the English language.”

Details

Show Answer ❌ False.

An alphabet can be any finite, non-empty set of symbols – digits, emojis, machine instructions, etc.

Q3. Which of these could be the alphabet for a DFA that checks balanced parentheses?

A. {(, )}
B. {a, b}
C. {0, 1}
D. Any of the above

Details

Show Answer ✅ Correct: D

The concept of “balanced parentheses” depends on how we encode the input.

  • If we use actual parentheses → {(, )}
  • If we encode ( as 0 and ) as 1 → {0, 1}
  • If we encode ( as a and ) as b → {a, b}
    So all are possible alphabets.

Q4. Which of the following sets is not a valid alphabet?

A. {0, 1, 2, 3}
B. {a, e, i, o, u}
C. {x | x is any real number}
D. {🙂, 😐, 🙁}

Details

Show Answer ✅ Correct: C

  • An alphabet must be finite and non-empty.
  • C is infinite (all real numbers) → ❌
  • A, B, D are all finite and non-empty → ✅ valid alphabets.

Q5. True or False:
“The set Σ = {a, a, b} is a valid alphabet.”

Details

Show Answer ❌ False (as written).

  • An alphabet is a set, and sets do not allow duplicates.
  • Properly written, this should be Σ = {a, b}, which is a valid alphabet.
  • So the idea behind it is fine, but the notation {a, a, b} is mathematically sloppy.

Q6. Let Σ = {0, 1, 2} and Γ = {a, b}. Which statement is correct?

A. Σ is an alphabet but Γ is not.
B. Γ is an alphabet but Σ is not.
C. Both Σ and Γ are valid alphabets.
D. Neither Σ nor Γ is an alphabet.

Details

Show Answer ✅ Correct: C

  • Σ = {0, 1, 2} → finite, non-empty → ✅
  • Γ = {a, b} → finite, non-empty → ✅
    Any finite, non-empty set of symbols (digits, letters, anything) can be an alphabet.

Q7. Which of the following best describes an alphabet in Theory of Computation?

A. Any set of words in a language
B. Any finite, non-empty set of symbols
C. Any infinite set of symbols
D. The English letters a to z only

Details

Show Answer ✅ Correct: B

  • By definition, an alphabet is a finite, non-empty set of symbols.
  • A is talking about a language, not an alphabet.
  • C is infinite → ❌
  • D is just a specific example, not the general definition.

Q8. True or False:
“If Σ = {0, 1}, then the symbol 10 is an element of Σ.”

Details

Show Answer ❌ False.

  • Σ = {0, 1} means the symbols are 0 and 1.
  • 10 is a string over Σ (sequence of symbols), not a single symbol in Σ.
  • So 10 ∉ Σ, but 10 ∈ Σ* (set of all strings over Σ).

Q9. Consider Σ = {a, b, c}. Which of the following are strings over Σ?

  1. abc
  2. cabba
  3. acx
  4. ε (epsilon, empty string)

A. 1 and 2 only
B. 1, 2, and 4
C. 1, 3, and 4
D. All of them

Details

Show Answer ✅ Correct: B

  • Valid strings over Σ use only symbols from {a, b, c}.
  • abc ✅
  • cabba ✅
  • acx ❌ (contains x which is not in Σ)
  • ε ✅ (empty string is always allowed over any alphabet).

Q10. Let Σ = {a, b}. Which of the following is not a correct way to describe Σ?

A. Alphabet with symbols a and b
B. Set of symbols used to build strings
C. The set {a, b}
D. The set of all possible strings made from a and b

Details

Show Answer ✅ Correct: D

  • D describes Σ*, not Σ.
  • Σ is just the basic symbol set, not all strings.
  • A, B, C are all correct ways to talk about Σ.

Q11. True or False:
“The empty set ∅ can be used as an alphabet in Theory of Computation.”

Details

Show Answer ❌ False.

  • By definition, an alphabet must be non-empty.
  • ∅ has no symbols → we cannot form any strings at all.
  • So ∅ is not allowed as an alphabet.

Q12. You are designing a machine that reads RGB colors, encoded as R, G, B. What is a natural choice for the alphabet?

A. {R, G, B}
B. {red, green, blue}
C. {0, 1}
D. {R, G, B, 0, 1}

Details

Show Answer ✅ Correct: A

  • The most direct encoding is {R, G, B}.
  • B is also finite and non-empty, so it could be an alphabet, but typically in TOC we prefer single-character symbols, so A is the clean answer.
  • C could work if we re-encode colors in binary, but that’s not what the question says.
  • D mixes two encodings unnecessarily.

Q13. Let Σ = {a, b, c}. Which of the following statements is true?

A. Σ is a language.
B. Σ is an alphabet.
C. Σ must be infinite to be useful.
D. Σ contains all possible strings over {a, b, c}.

Details

Show Answer ✅ Correct: B

  • Σ is a finite, non-empty set of symbols → an alphabet.
  • A language is usually a set of strings over Σ, not just the symbol set itself.
  • C is wrong; alphabets must be finite, not infinite.
  • D describes Σ*, not Σ.

Q14. True or False:
“Once we fix an alphabet Σ, every string we study in that context must be built only from the symbols in Σ.”

Details

Show Answer ✅ True.

  • In a formal model, once we fix the alphabet, all strings, languages, and machines are defined with respect to that alphabet.
  • Using symbols outside Σ would mean we are changing the basic setup.
