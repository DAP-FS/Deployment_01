Multilayer Perceptron (MLP)

Let's discover How Deep Networks Learn Non-Linear Patterns.

info

Welcome to Deep Learning Foundations.

In this module, we will explore multilayer perceptrons that overcome the limitations of single-layer perceptrons by adding hidden layers and using backpropagation.

1. What is a Multilayer Perceptron?​

A Multilayer Perceptron (MLP) is a feedforward artificial neural network with one or more hidden layers between the input and output layers. Unlike the single-layer perceptron, MLPs can learn non-linear decision boundaries and solve complex problems like XOR.

Key Insight

The MLP overcomes three critical limitations:

01. Can learn non-linear patterns (like XOR)
02. Uses backpropagation for efficient training
03. Achieves universal approximation with enough neurons

MLPs are the foundation of modern deep learning and are used for classification, regression, and pattern recognition tasks.

2. Architecture and Components​

2.1 MLP Structure​

An MLP consists of three types of layers:

MLP Architecture

1. Input Layer

Receives the input features x₁, x₂, …, xₙ. Each neuron corresponds to one input feature.

2. Hidden Layers

One or more layers between input and output. Each hidden layer can have any number of neurons with non-linear activation functions.

3. Output Layer

Produces the final prediction. Number of neurons depends on the task (1 for binary, k for multi-class).

💡 Key Difference: Hidden layers with non-linear activations allow MLPs to model complex, non-linear relationships.

2.2 Mathematical Representation​

For a 2-layer MLP (1 hidden layer), the forward pass is:

Hidden Layer:

h=σ(W(1)x+b(1))\mathbf{h} = \sigma(\mathbf{W}^{(1)} \mathbf{x} + \mathbf{b}^{(1)})h=σ(W(1)x+b(1))

Output Layer:

y^=σ(W(2)h+b(2))\hat{y} = \sigma(\mathbf{W}^{(2)} \mathbf{h} + \mathbf{b}^{(2)})y^​=σ(W(2)h+b(2))

where:

  • W(1),W(2)\mathbf{W}^{(1)}, \mathbf{W}^{(2)}W(1),W(2) are weight matrices
  • b(1),b(2)\mathbf{b}^{(1)}, \mathbf{b}^{(2)}b(1),b(2) are bias vectors
  • σ\sigmaσ is a non-linear activation function (e.g., sigmoid, ReLU)
  • h\mathbf{h}h is the hidden layer output
Why Non-Linearity Matters

Without non-linear activations, stacking multiple layers would be equivalent to a single layer! The non-linearity is what gives MLPs their power to learn complex patterns.

3. Activation Functions​

Activation functions introduce non-linearity into the network.

3.1 Common Activation Functions​

Sigmoid (Logistic)

Formula

σ(z)=11+e−z\sigma(z) = \frac{1}{1 + e^{-z}}σ(z)=1+e−z1​

Range

(0,1)(0, 1)(0,1) — outputs probabilities

Use Case

Binary classification output layers

Pros/Cons

✅ Smooth gradient
❌ Vanishing gradient problem for deep networks

Hyperbolic Tangent (Tanh)

Formula

tanh⁡(z)=ez−e−zez+e−z\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}tanh(z)=ez+e−zez−e−z​

Range

(−1,1)(-1, 1)(−1,1) — zero-centered

Use Case

Hidden layers (better than sigmoid)

Pros/Cons

✅ Zero-centered output
❌ Still suffers from vanishing gradients

ReLU (Rectified Linear Unit)

Formula

ReLU(z)=max⁡(0,z)\text{ReLU}(z) = \max(0, z)ReLU(z)=max(0,z)

Range

[0,∞)[0, \infty)[0,∞) — unbounded above

Use Case

Most popular for hidden layers

Pros/Cons

✅ Fast computation, no vanishing gradient
❌ Dead neurons problem (neurons can die)

Softmax

Formula

softmax(zi)=ezi∑jezj\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j} e^{z_j}}softmax(zi​)=∑j​ezj​ezi​​

Range

(0,1)(0, 1)(0,1) and ∑isoftmax(zi)=1\sum_i \text{softmax}(z_i) = 1∑i​softmax(zi​)=1

Use Case

Multi-class classification output layer [web:57][web:60]

Pros/Cons

✅ Outputs probability distribution
✅ Works well with cross-entropy loss

3.2 Activation Function Comparison​

Recommendation

Use ReLU for hidden layers and Softmax for multi-class output.

4. Backpropagation Algorithm​

Backpropagation is the algorithm used to train MLPs by computing gradients of the loss with respect to weights.

4.1 The Three Phases​

Phase 1: Forward Pass

What Happens

Feed inputs through the network, compute outputs at each layer, and calculate the loss.

Formula

L=Loss(y,y^)\mathcal{L} = \text{Loss}(y, \hat{y})L=Loss(y,y^​)

Phase 2: Backward Pass

What Happens

Propagate gradients of the loss backward from output to input using the chain rule.

Chain Rule

∂L∂wij(l)=∂L∂zi(l)⋅∂zi(l)∂wij(l)\frac{\partial \mathcal{L}}{\partial w_{ij}^{(l)}} = \frac{\partial \mathcal{L}}{\partial z_{i}^{(l)}} \cdot \frac{\partial z_{i}^{(l)}}{\partial w_{ij}^{(l)}}∂wij(l)​∂L​=∂zi(l)​∂L​⋅∂wij(l)​∂zi(l)​​

Phase 3: Gradient Descent Update

What Happens

Update weights by taking a small step in the opposite direction of the gradient.

Update Rule

wijnew=wijold−α∂L∂wijw_{ij}^{\text{new}} = w_{ij}^{\text{old}} - \alpha \frac{\partial \mathcal{L}}{\partial w_{ij}}wijnew​=wijold​−α∂wij​∂L​

💡 Learning Rate: α\alphaα controls the step size. Too large → unstable, too small → slow convergence.

5. Solving the XOR Problem​

The XOR problem cannot be solved by a single perceptron, but a 2-layer MLP can solve it easily [web:59][web:62]!

5.1 XOR Truth Table​

x1x_1x1​x2x_2x2​XOR Output
000
011
101
110
Why Single Perceptron Fails

XOR is not linearly separable. No single straight line can separate the positive cases 0 from the negative cases 1.

5.2 MLP Solution Architecture​

We'll use a 2-layer MLP [web:59][web:62]:

  • Input layer: 2 neurons (x1,x2x_1, x_2x1​,x2​)
  • Hidden layer: 2 neurons with sigmoid activation
  • Output layer: 1 neuron with sigmoid activation

4.2 Backpropagation Step-by-Step​

Consider a simple 2-layer MLP for binary classification:

  • Input: x∈Rn\mathbf{x} \in \mathbb{R}^{n}x∈Rn
  • Hidden layer (size mmm): weights W(1)∈Rm×n\mathbf{W}^{(1)} \in \mathbb{R}^{m \times n}W(1)∈Rm×n, bias b(1)∈Rm\mathbf{b}^{(1)} \in \mathbb{R}^{m}b(1)∈Rm
  • Output layer (1 neuron): weights W(2)∈R1×m\mathbf{W}^{(2)} \in \mathbb{R}^{1 \times m}W(2)∈R1×m, bias b(2)∈Rb^{(2)} \in \mathbb{R}b(2)∈R
  • Hidden activation: σ(1)\sigma^{(1)}σ(1) (e.g., ReLU, tanh)
  • Output activation: sigmoid σ(z)=11+e−z\sigma(z) = \dfrac{1}{1 + e^{-z}}σ(z)=1+e−z1​
  • True label: y∈{0,1}y \in \{0, 1\}y∈{0,1}

4.2.1 Forward Pass (Recap)​

We first compute the outputs layer by layer:

Hidden layer:

z(1)=W(1)x+b(1)\mathbf{z}^{(1)} = \mathbf{W}^{(1)} \mathbf{x} + \mathbf{b}^{(1)}z(1)=W(1)x+b(1) h=σ(1)(z(1))\mathbf{h} = \sigma^{(1)}\big(\mathbf{z}^{(1)}\big)h=σ(1)(z(1))

Output layer:

z(2)=W(2)h+b(2)z^{(2)} = \mathbf{W}^{(2)} \mathbf{h} + b^{(2)}z(2)=W(2)h+b(2) y^=σ(z(2))\hat{y} = \sigma\big(z^{(2)}\big)y^​=σ(z(2))

For binary classification, a common loss is binary cross-entropy:

L(y,y^)=−[ylog⁡(y^)+(1−y)log⁡(1−y^)]\mathcal{L}(y, \hat{y}) = -\Big[ y \log(\hat{y}) + (1 - y)\log(1 - \hat{y}) \Big]L(y,y^​)=−[ylog(y^​)+(1−y)log(1−y^​)]

4.2.2 Gradients at the Output Layer​

We now compute how the loss changes with respect to the output layer parameters.

Step 1 – Gradient w.r.t. z(2)z^{(2)}z(2)

For sigmoid + binary cross-entropy, a very useful simplification is:

∂L∂z(2)=y^−y\frac{\partial \mathcal{L}}{\partial z^{(2)}} = \hat{y} - y∂z(2)∂L​=y^​−y

Call this:

δ(2)=y^−y\delta^{(2)} = \hat{y} - yδ(2)=y^​−y

Step 2 – Gradients w.r.t. output weights and bias

Using the chain rule:

∂L∂W(2)=δ(2) h⊤\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(2)}} = \delta^{(2)} \, \mathbf{h}^\top∂W(2)∂L​=δ(2)h⊤ ∂L∂b(2)=δ(2)\frac{\partial \mathcal{L}}{\partial b^{(2)}} = \delta^{(2)}∂b(2)∂L​=δ(2)

4.2.3 Backpropagating to the Hidden Layer​

Now we send the error signal backwards into the hidden layer.

Step 3 – Error at hidden layer

First pass the error through the output weights:

∂L∂h=(W(2))⊤δ(2)\frac{\partial \mathcal{L}}{\partial \mathbf{h}} = (\mathbf{W}^{(2)})^\top \delta^{(2)}∂h∂L​=(W(2))⊤δ(2)

Then multiply element-wise by the derivative of the hidden activation:

δ(1)=∂L∂z(1)=((W(2))⊤δ(2))⊙σ(1)′(z(1))\delta^{(1)} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{(1)}} = \left( (\mathbf{W}^{(2)})^\top \delta^{(2)} \right) \odot \sigma^{(1)\prime}\big(\mathbf{z}^{(1)}\big)δ(1)=∂z(1)∂L​=((W(2))⊤δ(2))⊙σ(1)′(z(1))

where ⊙\odot⊙ is element-wise (Hadamard) product.

Example derivatives of σ(1)\sigma^{(1)}σ(1):

  • If σ(1)\sigma^{(1)}σ(1) is ReLU: 1 & \text{if } z > 0 \\ 0 & \text{if } z \le 0 \end{cases}$$
  • If σ(1)\sigma^{(1)}σ(1) is tanh:
    σ(1)′(z)=1−tanh⁡2(z)\sigma^{(1)\prime}(z) = 1 - \tanh^2(z)σ(1)′(z)=1−tanh2(z)

4.2.4 Gradients for Hidden Layer Weights and Bias​

Using δ(1)\delta^{(1)}δ(1):

Hidden weights:

∂L∂W(1)=δ(1) x⊤\frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(1)}} = \delta^{(1)} \, \mathbf{x}^\top∂W(1)∂L​=δ(1)x⊤

Hidden bias:

∂L∂b(1)=δ(1)\frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(1)}} = \delta^{(1)}∂b(1)∂L​=δ(1)

4.2.5 Parameter Update (Gradient Descent)​

Finally, we update all parameters using learning rate α\alphaα:

Output layer:

W(2)←W(2)−α∂L∂W(2)\mathbf{W}^{(2)} \leftarrow \mathbf{W}^{(2)} - \alpha \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(2)}}W(2)←W(2)−α∂W(2)∂L​ b(2)←b(2)−α∂L∂b(2)b^{(2)} \leftarrow b^{(2)} - \alpha \frac{\partial \mathcal{L}}{\partial b^{(2)}}b(2)←b(2)−α∂b(2)∂L​

Hidden layer:

W(1)←W(1)−α∂L∂W(1)\mathbf{W}^{(1)} \leftarrow \mathbf{W}^{(1)} - \alpha \frac{\partial \mathcal{L}}{\partial \mathbf{W}^{(1)}}W(1)←W(1)−α∂W(1)∂L​ b(1)←b(1)−α∂L∂b(1)\mathbf{b}^{(1)} \leftarrow \mathbf{b}^{(1)} - \alpha \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{(1)}}b(1)←b(1)−α∂b(1)∂L​
Intuition
  • Forward pass: compute predictions and loss.
  • Backward pass: compute how much each weight contributed to the error (gradients).
  • Update: move each weight slightly in the direction that reduces the loss.

Repeat this over many training examples (and epochs) to train the MLP.
