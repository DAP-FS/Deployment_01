Chapter 04

Turing Machines​

Let's discover Turing Machines in Theory of Computation.

Overview

In this chapter, you will learn:

  • What a Turing Machine (TM) is
  • The formal definition and components
  • How transitions work with tape operations
  • Examples of simple Turing Machines
  • Small practice questions to test yourself

0. Motivation – Beyond Finite Automata​

Why Turing Machines?

  • DFAs and PDAs have limitations:

    • DFAs: No memory beyond states
    • PDAs: Stack-based memory (LIFO only)

  • Turing Machines provide:

    • Unlimited memory (infinite tape)
    • Read and write capability
    • Bidirectional movement (left/right)

Turing Machines are the most powerful model of computation we study. They can recognize all computable functions.

1. What is a Turing Machine?​

A Turing Machine (TM) is a mathematical model of computation consisting of:

  • An infinite tape divided into cells
  • A read/write head that can move left or right
  • A finite control (states) that determines behavior
Intuition

Think of a Turing Machine as:

  • A program (finite control with states)
  • Running on a computer with unlimited memory (infinite tape)
  • That can read, write, and move on the tape

2. Formal Definition​

Formal Definition

A Turing Machine is a 7-tuple:

M=(Q,Σ,Γ,δ,q0,B,F)M = (Q, \Sigma, \Gamma, \delta, q_0, B, F)M=(Q,Σ,Γ,δ,q0​,B,F)

where:

  1. QQQ = finite set of states
  2. Σ\SigmaΣ = input alphabet (does not contain blank symbol)
  3. Γ\GammaΓ = tape alphabet (includes Σ\SigmaΣ and blank symbol BBB)
  4. δ\deltaδ = transition function: δ:Q×Γ→Q×Γ×{L,R}\delta: Q \times \Gamma \rightarrow Q \times \Gamma \times \{L, R\}δ:Q×Γ→Q×Γ×{L,R}
  5. q0∈Qq_0 \in Qq0​∈Q = start state
  6. B∈ΓB \in \GammaB∈Γ = blank symbol
  7. F⊆QF \subseteq QF⊆Q = set of final/accepting states

2.1 Components Explained​

States (QQQ)​

  • Similar to DFA/NFA states
  • Finite set representing the "program" of the TM
  • Include start state q0q_0q0​ and accepting states FFF

Alphabets (Σ\SigmaΣ and Γ\GammaΓ)​

  • Input alphabet Σ\SigmaΣ: Symbols in the input string
  • Tape alphabet Γ\GammaΓ: All symbols that can appear on tape
    • Must satisfy: Σ⊂Γ\Sigma \subset \GammaΣ⊂Γ
    • Contains special blank symbol BBB
Example – Alphabets

For a TM processing binary strings:

  • Σ={0,1}\Sigma = \{0, 1\}Σ={0,1} (input alphabet)
  • Γ={0,1,X,Y,B}\Gamma = \{0, 1, X, Y, B\}Γ={0,1,X,Y,B} (tape alphabet)
    • X,YX, YX,Y are "marker" symbols
    • BBB is the blank symbol

Transition Function (δ\deltaδ)​

The heart of the Turing Machine[web:2][web:6].

δ(q,a)=(q′,b,D)\delta(q, a) = (q', b, D)δ(q,a)=(q′,b,D)

Meaning:

  • Current state: qqq
  • Current symbol read: aaa
  • Next state: q′q'q′
  • Write symbol: bbb (replaces aaa on tape)
  • Direction: D∈{L,R}D \in \{L, R\}D∈{L,R} (move head Left or Right)
Important
  • The head always moves (either L or R) after each transition
  • The symbol under the head is always replaced (can be same symbol)

2.2 Transition Notation​

We write transitions in multiple ways:

(A) Functional Notation​

δ(q0,a)=(q1,b,R)\delta(q_0, a) = (q_1, b, R)δ(q0​,a)=(q1​,b,R)

Read as:
"In state q0q_0q0​, reading symbol aaa, write bbb, move Right, go to state q1q_1q1​"

7. Practice Questions – Detailed​

Question 1 – Palindrome Detector (Binary)​

Practice Question

Problem: Design a TM that accepts all binary palindromes. A palindrome is a string that reads the same forwards and backwards.

  • Input alphabet: Σ={0,1}\Sigma = \{0,1\}Σ={0,1}
  • Goal: Accept if input is palindrome; otherwise reject.

Intuition:

  • Check the first and last symbols of the string.
  • Mark matched symbols to avoid rechecking.
  • Repeat inward until all symbols are matched or a mismatch is found.

Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Start, look for first unmarked symbol
  • q1q_1q1​: Last symbol was 0, move left to match first symbol
  • q2q_2q2​: Last symbol was 1, move left to match first symbol
  • qfq_fqf​: Accept
  • qrq_rqr​: Reject

Step 2 – Transition Function (simplified):

StateSymbolNext StateWriteMove
q0q_0q0​0q1q_1q1​XR
q0q_0q0​1q2q_2q2​YR
q0q_0q0​Xq0q_0q0​XR
q0q_0q0​Yq0q_0q0​YR
q0q_0q0​Bqfq_fqf​BR
q1q_1q1​0q1q_1q1​0R
q1q_1q1​Bqrq_rqr​BR

Step 3 – Trace Example (101):

  1. Tape: 1 0 1 B B ...
  2. Mark first 1 → Y 0 1 B → move right to last 1
  3. Last 1 matches → mark Y → Y 0 Y B
  4. Only 0 left → matches itself → accept

Question 2 – Equal Number of 0s and 1s​

Practice Question

Problem: Design a TM that accepts binary strings with equal number of 0s and 1s.

  • Example accepted: 0101, 1100
  • Example rejected: 001, 1110

Intuition:

  • Pair each 0 with a 1 one by one.
  • Mark symbols as processed to avoid recounting.
  • Accept if all symbols are paired.
Click to view solution
Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Start, look for unmarked 0 or 1
  • q1q_1q1​: Found 0, searching for 1 to pair
  • q2q_2q2​: Found 1, searching for 0 to pair
  • qfq_fqf​: Accept
  • qrq_rqr​: Reject

Step 2 – Trace Example (1010):

  1. Mark first 1 → Y 0 1 0
  2. Mark first 0 after that → Y X 1 0
  3. Continue pairing → Y X Y X
  4. All symbols marked → accept

Question 3 – Strings Ending with 00​

Practice Question

Problem: Design a TM that accepts binary strings ending with 00.

  • Example accepted: 100, 1100
  • Example rejected: 101, 111

Intuition:

  • Scan to the end of the string.
  • Check last two symbols.
  • Accept if they are both 0; otherwise reject.
Click to view solution
Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Move right until blank
  • q1q_1q1​: Last symbol was 0
  • q2q_2q2​: Second last symbol was 0 → accept
  • qrq_rqr​: Otherwise → reject

Step 2 – Trace Example (100):

  1. Tape: 1 0 0 B → move right to blank
  2. Last symbol 0 → q1q_1q1​
  3. Previous symbol 0 → q2q_2q2​ → accept

Question 4 – Binary Incrementer (Transducer)​

Practice Question

Problem: Design a TM transducer that increments a binary number by 1.

  • Input: Binary number (e.g., 111)
  • Output: Binary number after increment (e.g., 1000)

Intuition:

  • Move to the last bit.
  • Add 1 with carry rules like binary addition.
  • Write result on tape.
Click to view solution
Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Move right to end
  • q1q_1q1​: Add 1 at last position
  • q2q_2q2​: Propagate carry left if needed
  • qfq_fqf​: Accept

Step 2 – Trace Example (111):

  1. Tape: 1 1 1 B
  2. Add 1 to last 1 → becomes 0, carry → move left
  3. Add 1 to next 1 → becomes 0, carry
  4. Add 1 to first 1 → becomes 0, carry
  5. Left of first → write 1 → result 1000 → accept

Question 5 – Flip All Bits (Transducer)​

Practice Question

Problem: Design a TM transducer that flips all bits in a binary string.

  • Input: 1101
  • Output: 0010

Intuition:

  • Move left-to-right.
  • If 0 → write 1, if 1 → write 0.
  • Stop at blank → accept.
Click to view solution
Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Flip current symbol
  • qfq_fqf​: Accept when blank reached

Step 2 – Trace Example (1101):

  1. 1101 → flip first 1 → 0101
  2. Next 1 → 0011
  3. Next 0 → 1111
  4. Next 1 → 1110 → reach blank → accept

Question 6 – Unary Multiplication by 2 (Transducer)​

Practice Question

Problem: Design a TM transducer that doubles a unary number.

  • Input: 111
  • Output: 111111

Intuition:

  • Copy all 1s to the right.
  • Use markers to avoid copying the same symbol twice.
  • Accept when all symbols are copied.
Click to view solution
Solution (Step-by-Step)

Step 1 – States:

  • q0q_0q0​: Move to first unmarked 1
  • q1q_1q1​: Copy 1 to end
  • q2q_2q2​: Move back to next unmarked 1
  • qfq_fqf​: Accept

Step 2 – Trace Example (111):

  1. Tape: 111 B B ...
  2. Copy first 1 → 1111 B ...
  3. Copy second 1 → 111111 B ...
  4. All symbols copied → accept
