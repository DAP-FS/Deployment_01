Chapter05

Let's discover The Simplest Artificial Neural Network.

info

Welcome to the foundation of Neural Networks and Deep Learning.

In this module, we will build the foundational understanding of how a single artificial neuron learns to classify data and what limitations it has.

1. What is a Perceptron?​

The perceptron is the simplest form of an artificial neural network and serves as the building block for understanding modern deep learning. It is a binary linear classifier invented by Frank Rosenblatt in 1958 that learns to separate two classes by finding an optimal decision boundary in the feature space.

Key Insight

The perceptron answers three fundamental questions:

01. Can a machine learn from data?
02. How does it adjust its parameters?
03. What are the limits of linear classification?

A perceptron is a supervised learning algorithm that performs binary classification by computing a weighted sum of input features and applying an activation function to produce an output.

2. Architecture and Components​

2.1 The Perceptron Structure​

A perceptron consists of four main components:

Core Components

1. Input Layer

The data points x₁, x₂, …, xₙ representing each feature in the dataset.

2. Weights

Coefficients w₁, w₂, …, wₙ that are learned during training to weight each input feature.

3. Summation Function

Computes the weighted sum: z = Σ(wᵢxᵢ) + b

4. Activation Function

A step function that decides whether the neuron "fires" based on whether the weighted sum exceeds a threshold.

💡 Intuition: Think of a perceptron as a decision-making unit that weighs evidence (inputs) and makes a binary choice (output).

2.2 Mathematical Representation​

The perceptron computes a linear combination of inputs and weights, then applies a step function to generate the final prediction.

Forward Pass​

The weighted sum is calculated as:

z=w1x1+w2x2+⋯+wnxn+b=w⋅x+bz = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w} \cdot \mathbf{x} + bz=w1​x1​+w2​x2​+⋯+wn​xn​+b=w⋅x+b

where (b) is the bias term. The activation function (Heaviside step function) then produces the output:

y^={1if z≥00if z<0\hat{y} = \begin{cases} 1 & \text{if } z \ge 0 \\ 0 & \text{if } z < 0 \end{cases}y^​={10​if z≥0if z<0​

This creates a linear decision boundary in the feature space.

Mathematical Notation
  • Input vector: x=[x1,x2,…,xn]\mathbf{x} = [x_1, x_2, \ldots, x_n]x=[x1​,x2​,…,xn​]
  • Weight vector: w=[w1,w2,…,wn]\mathbf{w} = [w_1, w_2, \ldots, w_n]w=[w1​,w2​,…,wn​]
  • Bias: bbb (shifts the decision boundary)
  • Dot product: w⋅x=∑i=1nwixi\mathbf{w} \cdot \mathbf{x} = \sum_{i=1}^{n} w_i x_iw⋅x=∑i=1n​wi​xi​

🔎 Key Idea: The perceptron computes: "Is the weighted evidence strong enough to classify this as positive?"

3. The Perceptron Learning Algorithm​

The perceptron learns using the perceptron learning rule, which updates weights based on prediction errors.

3.1 Weight Update Rule​

winew=wiold+α⋅(y−y^)⋅xiw_i^{\text{new}} = w_i^{\text{old}} + \alpha \cdot (y - \hat{y}) \cdot x_iwinew​=wiold​+α⋅(y−y^​)⋅xi​ bnew=bold+α⋅(y−y^)b^{\text{new}} = b^{\text{old}} + \alpha \cdot (y - \hat{y})bnew=bold+α⋅(y−y^​)

where:

  • α\alphaα is the learning rate (typically 0.01 to 0.5)
  • yyy is the true label (0 or 1)
  • y^\hat{y}y^​ is the predicted label (0 or 1)
  • xix_ixi​ is the input feature

5. Geometric Interpretation​

5.1 Decision Boundary​

For a 2D feature space, the decision boundary is a line:

w1x1+w2x2+b=0w_1 x_1 + w_2 x_2 + b = 0w1​x1​+w2​x2​+b=0
Geometric View
  • Above the line (w1x1+w2x2+b>0w_1 x_1 + w_2 x_2 + b > 0w1​x1​+w2​x2​+b>0): Class 1 (Positive)
  • Below the line (w1x1+w2x2+b<0w_1 x_1 + w_2 x_2 + b < 0w1​x1​+w2​x2​+b<0): Class 0 (Negative)
  • On the line: Decision boundary

📐 The weight vector w\mathbf{w}w is perpendicular to the decision boundary.

For our AND gate, the final decision boundary is:

0.4x1+0.4x2=0.5⇒x1+x2=1.250.4x_1 + 0.4x_2 = 0.5 \quad \Rightarrow \quad x_1 + x_2 = 1.250.4x1​+0.4x2​=0.5⇒x1​+x2​=1.25

Points where x1+x2≥1.25x_1 + x_2 \ge 1.25x1​+x2​≥1.25 are classified as 1.

5.2 Learning as Geometric Rotation​

During training, weight updates rotate and shift the decision boundary to better separate the two classes. When a point is misclassified:

  • The boundary rotates toward correctly classified regions
  • The goal: completely separate the two classes

9. Limitations​

Despite its importance, the perceptron has critical limitations:

Key Limitations
  • Linear Separability Required: Only works on linearly separable problems
  • XOR Problem: Cannot solve XOR (requires multilayer network)
  • No Hidden Layers: Lacks depth for complex patterns
  • Binary Only: Cannot directly handle multi-class problems
  • No Probabilistic Output: Only hard 0/1 predictions
  • Sensitive to Scaling: Requires feature normalization

These limitations led to multilayer perceptrons (MLPs) and modern deep learning.

10. Key Takeaways​

🎓 Essential Concepts

  • Perceptron is a linear binary classifier learning from errors
  • Weight vector defines a decision boundary (hyperplane)
  • Training uses perceptron learning rule: wi=wi+α⋅(y−y^)⋅xiw_i = w_i + \alpha \cdot (y - \hat{y}) \cdot x_iwi​=wi​+α⋅(y−y^​)⋅xi​
  • Only updates weights on mistakes
  • Converges in finite steps for linearly separable data
  • Cannot solve non-linear problems like XOR
