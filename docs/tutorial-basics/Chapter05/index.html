Chapter05

Pushdown Automata & Context-Free Grammars​

Let's discover Pushdown Automata (PDA) and their connection with Context-Free Grammars (CFGs).

Overview

In this chapter (≈ 9 hours of teaching + practice), you will learn:

  • What a Pushdown Automaton (PDA) is
  • Instantaneous Description (ID) and language of a PDA
  • Acceptance by final state and acceptance by empty stack
  • Deterministic PDA (DPDA) vs Non-deterministic PDA
  • Context-Free Grammar (CFG) basics
  • Equivalence of PDA and CFG
    • Converting CFG → PDA
    • Converting PDA → CFG
  • Practice questions (with stepwise hints/solutions)

0. Motivation – Why Pushdown Automata?​

Why PDA?

  • Finite Automata (FA) cannot handle:

    • Matching balanced parentheses
    • Languages like {anbn∣n≥0}\{ a^n b^n \mid n \ge 0 \}{anbn∣n≥0}

  • We need extra memory but more structured than TM:

    • PDA uses a stack (LIFO memory)
    • Useful for nested structures, like:
      • Parentheses in expressions
      • Block structures in programming languages
      • HTML/XML tags

So, PDA is a model between DFA and TM:

  • More powerful than FA
  • Less powerful than Turing Machine
  • Perfect for context-free languages

1. What is a Pushdown Automaton (PDA)?​

A Pushdown Automaton (PDA) is a finite automaton equipped with a stack.

  • Reads input left to right
  • Uses a stack to store symbols
  • Can push, pop, or ignore the stack top
  • Can non-deterministically choose transitions
Intuition

Think of PDA as:

  • A DFA with extra memory (stack)
  • Stack helps to remember counts or nested structures
  • Each move can:
    • Read a symbol from input (or ϵ\epsilonϵ = no symbol)
    • Check top of stack
    • Change state and modify stack

2. Formal Definition of PDA​

Formal Definition

A Pushdown Automaton (PDA) is a 7-tuple:

M=(Q,Σ,Γ,δ,q0,Z0,F)M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)M=(Q,Σ,Γ,δ,q0​,Z0​,F)

where:

  1. QQQ = finite set of states
  2. Σ\SigmaΣ = input alphabet
  3. Γ\GammaΓ = stack alphabet
  4. δ\deltaδ = transition function δ:Q×(Σ∪{ϵ})×Γ→P(Q×Γ∗)\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to \mathcal{P}(Q \times \Gamma^*)δ:Q×(Σ∪{ϵ})×Γ→P(Q×Γ∗)
  5. q0∈Qq_0 \in Qq0​∈Q = start state
  6. Z0∈ΓZ_0 \in \GammaZ0​∈Γ = initial stack symbol
  7. F⊆QF \subseteq QF⊆Q = set of final/accepting states

2.1 Meaning of Transition​

A transition
δ(q,a,X)∋(p,γ)\delta(q, a, X) \ni (p, \gamma)δ(q,a,X)∋(p,γ)
means:

  • PDA is in state q
  • Reads symbol a from input (or ϵ\epsilonϵ = no input)
  • Top of stack is X
  • Then PDA can:
    • Go to state p
    • Pop X and push the string γ (could be empty, or multiple symbols)

3. Instantaneous Description (ID) of a PDA​

Instantaneous Description (ID)

An Instantaneous Description (ID) of a PDA is a snapshot of its current configuration:

(q,w,α)(q, w, \alpha)(q,w,α)

where:

  • q = current state
  • w = remaining input (unread portion)
  • α = current stack contents, with leftmost symbol as top

We write one move as:

(q,aw,Xβ)⊢(p,w,γβ)(q, aw, X\beta) \vdash (p, w, \gamma\beta)(q,aw,Xβ)⊢(p,w,γβ)

if

δ(q,a,X)∋(p,γ)\delta(q, a, X) \ni (p, \gamma)δ(q,a,X)∋(p,γ)

4. Language of a PDA​

A PDA can define a language in two standard ways:

  1. Acceptance by Final State
  2. Acceptance by Empty Stack

4.1 Acceptance by Final State​

Acceptance by Final State

A string www is accepted by final state if:

  • Starting from (q0,w,Z0)(q_0, w, Z_0)(q0​,w,Z0​)
  • PDA reaches some final state f∈Ff \in Ff∈F
  • (Stack can be anything)

Write:

(q0,w,Z0)⊢∗(f,ϵ,α)for some f∈F,α∈Γ∗(q_0, w, Z_0) \vdash^* (f, \epsilon, \alpha) \quad \text{for some } f \in F, \alpha \in \Gamma^*(q0​,w,Z0​)⊢∗(f,ϵ,α)for some f∈F,α∈Γ∗

4.2 Acceptance by Empty Stack​

Acceptance by Empty Stack

A string www is accepted by empty stack if:

  • Starting from (q0,w,Z0)(q_0, w, Z_0)(q0​,w,Z0​)
  • PDA reaches a configuration with empty stack
  • (State can be anything)

Write:

(q0,w,Z0)⊢∗(q,ϵ,ϵ)for some q∈Q(q_0, w, Z_0) \vdash^* (q, \epsilon, \epsilon) \quad \text{for some } q \in Q(q0​,w,Z0​)⊢∗(q,ϵ,ϵ)for some q∈Q
Important

For context-free languages, both acceptance modes are equivalent:

  • For every PDA by final state, we can construct an equivalent PDA by empty stack
  • And vice versa

5. Deterministic PDA (DPDA)​

Deterministic PDA (DPDA)

A PDA is deterministic if:

  • For every (state, input symbol or ε, stack top):
    • At most one possible move
  • No conflict between:
    • ε-move and input-consuming move for the same stack top

DPDA accepts a proper subset of context-free languages.
There exist CFLs that cannot be accepted by any DPDA (e.g., {anbncn} \{ a^n b^n c^n \}{anbncn} is not even CFL).

Examples of languages accepted by DPDA:

  • L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0} (deterministic)
  • Balanced parentheses language

6. Context-Free Grammars (CFG)​

Context-Free Grammar (CFG)

A CFG is a 4-tuple:

G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S)

where:

  1. VVV = set of variables (non-terminals)
  2. Σ\SigmaΣ = set of terminals
  3. RRR = set of productions of the form
    A→α,  A∈V,α∈(V∪Σ)∗A \to \alpha, \; A \in V, \alpha \in (V \cup \Sigma)^*A→α,A∈V,α∈(V∪Σ)∗
  4. SSS = start symbol

Example – CFG for L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0}​

  • Variables: V={S}V = \{S\}V={S}
  • Terminals: Σ={a,b}\Sigma = \{a, b\}Σ={a,b}
  • Productions:
    • S→aSb∣ϵS \to aSb \mid \epsilonS→aSb∣ϵ

7. Equivalence of PDA and CFG​

Key Theorem

A language is context-free
⟺
It is accepted by some PDA.

So:

  • For every CFG, we can construct an equivalent PDA.
  • For every PDA, we can construct an equivalent CFG.

8. Conversion: CFG → PDA​

8.1 Standard Construction (High level)​

Given CFG G=(V,Σ,R,S)G = (V, \Sigma, R, S)G=(V,Σ,R,S):

We construct PDA MMM that simulates leftmost derivations:

  • Stack holds variables and terminals
  • Start: push Start symbol S on stack
  • At each step:
    • If stack top is a variable A:
      • Non-deterministically replace A using some production A → α (push α on stack)
    • If stack top is a terminal matching current input symbol:
      • Pop it and move input head
    • Accept when:
      • Input is fully consumed and stack becomes empty

9. Conversion: PDA → CFG​

Idea:

  • Represent segments of computation as non-terminals
  • A variable like [pXq] means:
    “All strings that take PDA from state p with X on top to state q with X popped”.

Using such variables, we construct CFG rules based on transitions of PDA.

(You may keep this section at a more intuitive level for 1st-time learners.)

10. Practice Questions – PDA (Core)

Question 1 – PDA for L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0}​

Practice Question

Problem: Design a PDA (by empty stack) that accepts
L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0}

Click to view solution
Solution (Idea)

Intuition:

  • For each a, push a symbol (say X) onto the stack
  • When b starts, pop one X for each b
  • If stack becomes empty exactly when input ends → accept

States:

  • q0q_0q0​: Reading a’s and pushing
  • q1q_1q1​: Reading b’s and popping
  • Acceptance: empty stack

Transitions (informal):

  1. Start with stack symbol Z_0
  2. In q0q_0q0​:
    • On input a, stack top Z_0 or X → push X
    • On input b, move to q1q_1q1​
  3. In q1q_1q1​:
    • On input b, pop one X each time
  4. When input is finished and stack has Z_0:
    • Pop Z_0 via ε-move → empty stack → accept

Practice Question

Problem: Design a PDA that accepts all strings of balanced parentheses over alphabet { '(', ')' }.

Solution (Idea)

Intuition:

  • Push on (
  • Pop on )
  • If at any point we need to pop and stack is empty → reject
  • Accept when input over and stack is back to initial symbol

Sketch:

  • q0q_0q0​:
    • Read ( → push (
    • Read ) → pop (
  • Accept by empty stack when input finished and stack empty.

Question 3 – PDA for L={wwR∣w∈{0,1}∗}L = \{ ww^R \mid w \in \{0,1\}^* \}L={wwR∣w∈{0,1}∗} (Even-length palindromes)​

Practice Question

Problem: Design a PDA that accepts all even-length palindromes over {0,1}, i.e., strings of the form wwRww^RwwR.

Click to view solution
Solution (Sketch)

Intuition:

  • Non-deterministically guess the middle point
  • First half: push symbols
  • Second half: pop and match with input

States:

  • q0q_0q0​: pushing phase
  • q1q_1q1​: popping phase (after ε-move guess)

Idea:

  • In q0q_0q0​:
    • On 0/1: push symbol; stay in q0q_0q0​
    • ε-move to q1q_1q1​: guess that half is over
  • In q1q_1q1​:
    • On input symbol, pop stack and compare
  • Accept by empty stack when input over

Question 6 – CFG for L={0n1m0n∣n,m≥1}L = \{ 0^n 1^m 0^n \mid n,m \ge 1 \}L={0n1m0n∣n,m≥1}​

Practice Question

Problem: Give a CFG for
L={0n1m0n∣n,m≥1}.L = \{ 0^n 1^m 0^n \mid n,m \ge 1 \}.L={0n1m0n∣n,m≥1}.

Click to view solution
Solution (One possible CFG)
  • Start symbol: SSS

Productions:

  • S→0S0∣0T0S \to 0S0 \mid 0T0S→0S0∣0T0
  • T→1T∣1T \to 1T \mid 1T→1T∣1

Explanation:

  • Outer 0S0 or 0T0 ensure equal 0s on both sides
  • Middle T generates one or more 1s.

12. Practice – CFG ↔ PDA Conversions (3 + 3)

Question 7 – CFG → PDA for L={anbn}L = \{ a^n b^n \}L={anbn}​

Practice Question

Problem: Convert the CFG

  • S→aSb∣ϵS \to aSb \mid \epsilonS→aSb∣ϵ

to an equivalent PDA.

Click to view solution
Solution (Standard CFG → PDA idea)

Step 1 – PDA idea

  • Start with stack symbol S
  • When stack top is a variable, expand it using CFG rules
  • When stack top is a terminal, match with input

Construction (informal):

  • States: {qstart,q}\{q_{\text{start}}, q\}{qstart​,q}
  • At qstartq_{\text{start}}qstart​: push S and go to q
  • At q:
    • If stack top = S:
      • Use productions:
        • S → aSb: replace S by b S a (or push reversed)
        • S → ε: pop S
    • If stack top is a/b:
      • Read same input symbol and pop it
  • Accept by empty stack.

Question 9 – PDA → CFG for L={anbn}L = \{ a^n b^n \}L={anbn} PDA​

Practice Question

Problem: Take the PDA for L={anbn}L = \{ a^n b^n \}L={anbn} (from Q1) and outline how to construct equivalent CFG.

Click to view solution
Solution (High level)

Idea:

  • Create variables of form [pXq][pXq][pXq] where:
    • p, q are states
    • X is stack symbol
  • Variable [pXq][pXq][pXq] generates all strings that take PDA:
    • From state p with stack top X
    • To state q with X removed from stack

Then:

  1. For each transition that pushes stack symbols, add productions to relate variables.
  2. For transitions that only pop, add terminal productions.

In class, you can keep it intuitive and show only a small example.

Question 10 – Deterministic PDA Exercise​

Practice Question

Problem: Show that the language L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0} is accepted by a DPDA and outline why your PDA is deterministic.

Click to view solution
Solution (Sketch)
  • Use PDA from Question 1, but design transitions such that:
    • While reading a, only pushing is possible
    • When first b appears, move to new state where only popping X for each b is allowed
    • No ε-moves that conflict with input moves
  • For each (state, input symbol, stack top) there is at most one transition.

Hence, it is deterministic.

Question 11 – GATE Level: PDA Language Identification​

Practice Question

A PDA pushes one symbol X for every input a, and pops one X for every input b.
It rejects if a b is seen when stack only has initial symbol.
It accepts by empty stack.

Question: What language does it accept?

Click to view solution
Solution

The language is:

L={anbn∣n≥0}L = \{ a^n b^n \mid n \ge 0 \}L={anbn∣n≥0}

since:

  • PDA ensures equal numbers of a and b
  • All a must appear before b’s (because transitions are defined that way)
